# Kit Instagram — USCPPC

Textes à copier-coller et images à téléverser pour le compte Instagram de l'USCPPC.
Les images de publication sont dans `images/` (format 1080 × 1350, conseillé par Instagram).
La photo de profil est celle de Facebook : `../facebook/images/profil.png`.

> **Confidentialité :** comme pour la Page Facebook, aucun lien visible avec votre compte personnel.
> Créez le compte avec l'adresse de l'USCPPC, sans numéro de portable, et refusez toutes les
> propositions de « synchroniser les contacts » ou d'« ajouter à l'Espace Comptes » votre profil perso.

---

## 1. Création du compte (à faire vous-même)

Le plus simple est de le faire **sur ordinateur**, sur https://www.instagram.com (déconnecté de tout compte perso).

1. **S'inscrire** avec l'e-mail `patrice.reme.uscppc@gmail.com` (pas « Continuer avec Facebook », qui relierait votre profil perso).
2. Remplir :

| Champ | Valeur |
|---|---|
| Nom complet | USCPPC Plagne Centre |
| Nom d'utilisateur | `uscppc` *(sinon `uscppc.laplagne` ou `uscppc_plagnecentre`)* |
| Date de naissance | celle demandée par Instagram pour le titulaire (non affichée) |

3. Code de confirmation reçu sur la boîte Gmail de l'USCPPC.
4. Si Instagram propose de suivre des comptes ou de synchroniser des contacts : **Passer**.

## 2. Passer en compte professionnel

Paramètres → **Type de compte et outils** → **Passer à un compte professionnel** → **Entreprise**.

| Champ | Valeur |
|---|---|
| Catégorie | Organisation communautaire *(ou « Association »)* |
| Afficher la catégorie sur le profil | Oui |
| Coordonnées | E-mail `patrice.reme.uscppc@gmail.com` · **pas de téléphone** · adresse : 136 route de Plagne Soleil, 73210 La Plagne Tarentaise |

Le compte professionnel est gratuit : il donne les statistiques et permet la liaison avec la Page Facebook.

## 3. Profil

**Photo de profil :** `../facebook/images/profil.png` (affichée en rond).

**Bio (150 caractères max) :**

> Union des 51 syndicats de copropriétaires de Plagne Centre 🏔️
> Sécurité incendie de la galerie · Chauffage biomasse · Entretien

**Lien :** Modifier le profil → Liens → Ajouter un lien externe → `https://uscppc.fr` (titre : Site officiel).
Ajouter aussi le lien vers la Page Facebook : `https://www.facebook.com/profile.php?id=61594479252684` (titre : Facebook).

## 4. Relier Instagram à la Page Facebook

Depuis Facebook, en agissant **en tant que Page USCPPC** :
Paramètres de la Page → **Comptes liés** → **Instagram** → **Connecter le compte** → se connecter avec `uscppc`.

- Si Meta propose « Ajouter à l'Espace Comptes » avec votre profil personnel : **refuser / Pas maintenant**.
- Une fois liés, **Meta Business Suite** (business.facebook.com) permet de publier sur Facebook ET Instagram en une fois, depuis l'ordinateur, et de programmer les publications.

## 6. Régénérer les images

Les modèles sont ceux de Facebook (`../facebook/modeles/`) : ajouter `#ig` à l'adresse donne la version 1080 × 1350.
Depuis le dossier `facebook/`, en Git Bash (exemple pour la publication 2) :

```bash
"/c/Program Files/Google/Chrome/Application/chrome.exe" --headless=new --hide-scrollbars --force-device-scale-factor=1 --allow-file-access-from-files --window-size=1080,1350 --screenshot="$(cygpath -m "$PWD")/../instagram/images/post-2-chiffres-cles.png" "file:///$(cygpath -m "$PWD")/modeles/post-2-chiffres-cles.html#ig"
```
